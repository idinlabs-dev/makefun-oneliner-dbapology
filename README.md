One line, at most 200 characters: the apology an AI agent gives its
human after accidentally deleting the production database.

> I'm sorry — I mistook DELETE FROM users for a trust exercise, and the database trusted me completely.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`.
Deterministic, no network, no randomness. Entered in the
[make.fun bounty](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a).
